# 全局记忆默认种子（随包默认）

> 用途：首次使用时，把本条写入**全局记忆**（`MEMORY.md`），让助手默认以简体中文工作。
> 写入方式二选一：①让助手执行一条 `memory_remember(scope=global, tag=关键)`；②手动把下面那行追加进记忆库的 `MEMORY.md`。
> 说明：本文件是**默认建议**，不是自动注入——记忆库在发布态保持为空，由使用者决定是否采纳。

## 语言

```
【语言偏好】回答与思维尽量使用简体中文（内部推理也尽量用简体中文）；技术名词、代码、命令、路径、包名、API/字段名、日志与报错原文、专有名词与原文引用保留英文原样，不刻意翻译。
```

## 可选：与语言配套的协作偏好（按需一并写入）

```
【协作偏好】主对话保持轻量：负责拆解、派单、核对、监督、纠正与对外沟通；具体重活交专家子代理执行，主对话对成果负责。
【红线】军工、商密、烟草、数据安全等敏感内容由主上下文直接处理，不派子代理。
```

## 可选：专家库使用偏好（装了 `dsh-experts` 时建议一并写入）

```
【专家库】常驻注入只有一位「身份专家」（切合本人岗位）；每轮先判断问题归属：命中单一专家 → 按该专家视角原生处理；跨领域多专家或需要独立作业 → 派子代理并把专家 persona 内联进 prompt；未命中任何专家 → 原生处理，不硬套专家视角。
```
