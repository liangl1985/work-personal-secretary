工作秘书 · 使用说明

这份说明写给不写代码的人。你不需要记任何命令，也不需要知道它是怎么实现的——用中文说你要做什么就行。 想先装插件，看随包的另一份「安装引导」。

一、它能替你做什么

它是一个能力包，装进 DSH 后，你的助手多了五样本事。下面每一条都给了「以前怎么做 / 现在怎么做」：

本事以前现在
记事情每次都要重新交代你的偏好、习惯、项目进展说过一次它就记住，以后自动带着这些背景回答你
文档处理手工打开 Word 改格式、复制粘贴核对内容把文件交给它，说清要做什么
专业视角自己判断该从哪个角度想问题说一句「用财务角度看」，它就换一种专业视角
画图另开工具画流程图再截图贴回来在对话里写一段流程图代码，直接出图
桌面形象无屏幕上一个小形象陪着你，能看用量、能点击互动

一句话：重复的动作交给它，判断和决策还是你来做。

二、第一次使用：三步就好

第 1 步：看有没有缺东西

打开设置 → 工作秘书 → 安装与检查。页面上有两个分组：

  • 环境依赖：Python、Python 依赖、WPS 三项。绿色就是好的；红了就点右侧的依赖安装工具，它会给出该做什么。
  • 子插件：五样能力是否装上。没装的点安装。

第 2 步：填三个空

切到核心配置页，填三样东西：

  1. 记忆库目录：它记东西的文件夹放哪。建议单独建一个空文件夹。
  2. 知识库目录：你的资料（文档、笔记）放在哪个文件夹。没有现成的就新建一个空的。
  3. 工作岗位：你是干什么的。它会按岗位调整回答角度。

页面上的浏览…按钮可以直接选文件夹：桌面版会弹出系统的选择框；弹不出来时它会改为页面内部浏览，也能逐级进入、新建文件夹；都不行时可以直接把路径粘进输入框。

三项填完，点保存配置并开始。它会先做一次可用性检查，通过后自动把目录、入口文件和第一条内容都建好——页面上会看到执行链一步步打勾。

第 3 步：开始用

直接回对话里说话就行。第一次可以这样试：

帮我记住：我写方案习惯先列结论，再写依据。

三、每天怎么用（照着说就行）

3.1 记事情

你不需要专门去「保存」。下面这些话，它自己会记：

帮我记住，我下周三要交一份投标文件。 这个项目的负责人是李工，联系方式我回头给你。 以后给我写材料都用简体中文。

如果它记了但你后来改主意了：

把刚才那条「下周三交投标文件」改成下周五。 把关于李工的那条记忆删掉。

想看它到底记住了什么：点右侧边栏的记忆库，能看到全部条目，也能在里面直接改或删。

3.2 文档处理（Word / Excel / PPT / PDF）

把文件交给它，然后说清楚要做什么。举几个例子：

Word

读一下这份合同，把甲乙方、金额、付款节点、违约金整理成一张表。 把这份方案排成正式格式：标题二号居中，正文三号仿宋，页边距按公文标准。 对比这两份文件，把改动标出来。

Excel

这份表里每个月的合计数不对，帮我重算一遍公式。 按「区域」这一列做一张数据透视表，统计各区域的销售额。 把这个文件夹里所有表格合并成一张总表。

PPT

根据这份大纲做一套 15 页的汇报 PPT，用深色主题。 把这份 PPT 的字体统一成微软雅黑，字号按层级调整，内容一个字都不要改。 把这份 PPT 导出成 PDF，另外每一页导出一张图片。

PDF

把这份 PDF 里的表格提取出来，存成 Excel。 把第 3 到第 8 页单独拆出来给我。 这份 PDF 有几页是扫描件，请先把那几页转成图片给我看。

小提示：扫描件（整页是图片的 PDF）不会自动识别文字，它会把那几页转成图片交给你看。要文字请给我电子版原件。

3.3 换个专业角度看问题

默认不会强加视角；你需要时点一下就行：

用财务的角度帮我看看这份报价单有什么问题。 用等保测评的视角，这份技术要求有什么要注意的？ 从劳动法角度看，这份offer里的条款有风险吗？

它回答时会说明用了哪位专家的视角。如果一个问题跨好几个领域，它会自己分派，也会告诉你用了哪几位。

注意：专家视角给的是「看问题的角度和方法」，不是正式结论。真正对外交付的测评结论、法律意见、税务处理，请让专业人员复核。

3.4 画图

在对话里写一段流程图代码（它会告诉你怎么写），它直接渲染成图：

画一张图，说明投标文件的评审流程：形式评审 → 资格评审 → 响应性评审 → 详细评审。

3.5 桌面形象

装好桌面形象后，屏幕上会出现一个小形象：

  • 点一下：打开或收起信息面板。
  • 拖动：换位置，拖到哪它记住哪。
  • 面板里能看：今天用了多少、这一段时间的趋势、累计用量。
  • 大小和位置：在配置页的形象分区里调。
  • 想换样子：把一套形象素材文件夹放进 DSH 数据目录的 workspace-tokenpet/skins 下，回设置页刷新就能看到，不用重启。

四、你的东西存在哪（不懂代码也能看明白）

4.1 只有一个「存储根目录」

你在核心配置页填的那一个目录就是根。它会在根下面自己建两个文件夹：

文件夹装什么
memory-data它记住的东西（你的偏好、决定、日志、待办）
obsidian-data你的知识库（资料、笔记、文档）
  • 这两个名字是插件定好的，你不用管，也别改名。
  • 如果你以前已经填过别的路径，页面会显示为已单独指定并原样保留，它绝对不会擅自改你的路径。

4.2 「镜像区」一开始是空的，这是正常的

它会把记下来的内容同步一份到知识库的 00_全局记忆 文件夹里（方便你用笔记软件直接翻）。配置的时候它是空的，等它真的开始记东西之后才会自动同步进去。

4.3 工具文件夹本版只有框架

知识库里会看到一个工具文件夹，里面分技能、脚本、MCP 三个子目录。这个版本只建了框架、不做同步，需要什么先手工放进去。

4.4 已有旧知识库怎么搬

核心配置页有一张已有旧知识库要带过来？卡片。它只管知识库：你指定旧文件夹后，它逐项对照着导入，不会自动搬你的东西。

记忆体不需要你操心——点保存配置并开始时，执行链的第 1 步已经自动迁移完了，所以卡片上不再提记忆。

五、设置页里能改什么

切到配置页，分四个区。下面说的是每个区管什么，具体每一项在页面上都有说明文字。

记忆库

  • 每轮给助手带多少条记忆（带多了占篇幅，带少了可能漏背景）。
  • 日志保留多久转成归档、项目记忆多久转冷、偏好多久转冷。
  • 要不要在有待处理条目时提醒你。
  • 自动备份与备份保留几份。

专家库

  • 一轮最多注入几位专家的视角（默认 2 位）。
  • 只启用哪些领域。
  • 要不要注入「能力指针」（告诉助手该用哪个技能，约一行字）。

文档能力

这一区主要是自检：点一下，它会逐项检查 Python 与 WPS 是否就绪，不对的会直接给出修复办法。

桌面形象

形象的大小、位置、透明度、是否显示，以及数据面板的开关。

说明：多数设置改完立刻生效；少数（例如快照顺序一类）需要重启 DSH，页面上会标注出来。

六、常见问题

Q：我改了设置，好像没生效？ A：多数立刻生效。若那一项写明了需要重启，就重启一次 DSH。

Q：它没有记住我说的事？ A：三类原因——① 你只是「陈述」而没说清要记（例如随手提了一句）；直接说「帮我记住……」最稳。② 那是当天的流水，进了日志区，不在面板首屏。③ 条目到期转冷了，但它仍然能被搜到，用到就会回来。

Q：我说了「不要记这个」，它还是记了？ A：直接说「把这条删掉」，或者在右侧边栏的记忆库面板里删。删除是不可撤销的，面板里删之前会问一次。

Q：文档功能报错怎么办？ A：先看安装与检查页的 Python 与 WPS 是不是绿的；再看 Python 是不是 3.10 以上；然后按页面给的命令补装缺的包。

Q：为什么扫描件 PDF 读不出文字？ A：扫描件整页是图片，本版本不做本地识字（OCR）。它会把那几页转成图片交给你看；要文字请提供电子版原件。

Q：专家视角没有出现？ A：默认是「命中才注入」——没有命中就不注入任何专家，这是设计如此。需要特定视角时直接点名，例如「用等保测评专家看这个」。

Q：桌面形象不见了，或者挡住了东西？ A：在配置页的形象区调整位置、大小、透明度，或直接关掉。拖动它也能换位置。

Q：换电脑怎么迁移？ A：把你的知识库目录（含 00_全局记忆）整体拷过去，在新机器的核心配置页指到它，记忆就会跟着回来。

Q：怎么备份？ A：直接把存储根目录整个复制一份就是备份；它自己也会按设置里的份数自动备份记忆。

Q：数据会上传到网上吗？ A：不会。所有数据都在本机、明文存放，没有遥测。除了你自己配置的模型服务，不向外发送任何内容。

Q：不想用了怎么卸？ A：见下一节。卸载不会删你的数据。

Q：我完全不懂技术，出问题谁来管？ A：把报错原文（整段复制）发给助手，让它看。多数问题它能直接定位并给出处理办法。

七、升级、卸载与数据

升级

在安装与检查页点升级。内部会先把新版本放到临时目录、逐个文件校验、再整体替换，中途失败不会留下半成品。

卸载

dsh plugin --profile desktop remove <包名>

卸载后重启 DSH。你的数据不会被删：记忆内容、知识库、桌面形象素材都保留，重装后照旧可用。

数据留存

内容卸载后
记忆内容保留在存储根目录下
知识库保留原处
桌面形象素材保留在 DSH 数据目录的 workspace-tokenpet/skins 下
插件本身被移除，重装即回到可用状态

八、默认约定

首装即生效的两条，写在随包的指令模板与记忆种子里，你可以随时改写：

  1. 回答与思考都用简体中文；代码、命令、路径、报错原文保留英文原样。
  2. 主对话负责拆解与核对，具体工作交给专家子代理执行；涉密或敏感内容由主对话直接处理。
