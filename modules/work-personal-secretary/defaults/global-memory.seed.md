# 全局记忆默认种子（随包默认）

> **用途**：首次使用时把下面几条写入**全局记忆**（`MEMORY.md`），让助手默认以简体中文工作、并按集成体的协作方式干活。
> **写入方式**二选一：① 让助手执行 `memory_remember(scope=global, tag=关键)`；② 手动把下面的条目追加进记忆库的 `MEMORY.md`。
> **单一真源**：语言与协作的**完整规则**定义在**工作区 `AGENTS.md` 的「工作秘书」标记块**（DSH 每轮作为指令注入，约束力强于记忆层）。本文件只放**记忆层该有的兜底与指针**，不复述正文，避免两处措辞漂移。

## 语言（兜底条目）

```
【语言偏好】回答与思维尽量使用简体中文（内部推理也尽量用简体中文）；技术名词、代码、命令、路径、包名、API/字段名、日志与报错原文、专有名词与原文引用保留英文原样，不刻意翻译。完整规则见工作区 AGENTS.md 的「工作秘书」标记块。
```

## 协作与红线（指针条目）

```
【协作方式】主对话保持轻量（拆解 / 派单 / 核对 / 监督 / 纠正 / 对外沟通），具体工作交子代理执行；涉密或敏感内容（如军工、商密、烟草、数据安全等）由主上下文直接处理。规则正文见工作区 AGENTS.md 的「工作秘书」标记块。
【专家库】装了 dsh-experts 时：默认一位都不常驻（身份由记忆层承担）；任务命中关键词才注入对口专家，跨领域任务派子代理激活。规则正文见工作区 AGENTS.md 的「工作秘书」标记块。
【工具与技能】DSH 与插件的使用技巧（命令、设置、排障、踩坑）见知识库「工具/技能」目录下的 DSH与插件使用技巧.md；完整清单与版本基线以该文件为准。
```

## 使用说明（不写入记忆）

- 这些是**建议**，不是自动注入 —— 记忆库在发布态保持为空，由使用者决定是否采纳、是否改写。
- 若使用者**未**使用 `defaults/AGENTS.zh-CN.md` 模板，则上面的「语言（兜底条目）」仍可独立生效。
- 需要更严的口径（例如要求「一律」用简体中文）时，请在使用者自己的 `AGENTS.md` 块外段落声明 —— 那是个人加严，不属发布件默认。
