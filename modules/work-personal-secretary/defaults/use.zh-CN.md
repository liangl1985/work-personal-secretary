# 工作秘书 · 使用说明

五分钟上手，以及五个子插件各自做什么。

## 一、这个插件是什么

一个集成体把五套能力装到一起：记忆、文档、专家、图表、桌面形象。它不替你做业务判断，负责把重复动作接过去——记东西、翻资料、出文档、按专业角度拆问题。

## 二、第一次使用

1. **安装与检查**：看环境与子插件是否齐，有缺项时点「查看安装引导」。
2. **核心配置**：填记忆库目录与 Obsidian 目录，选工作岗位，点「保存配置并开始」生成目录骨架、入口与首条内容。
3. **配置**：按需调整子插件设置；不确定的保持默认。

## 三、五个子插件各做什么

| 子插件 | 做什么 | 怎么用 |
|---|---|---|
| 记忆库 | 三级记忆：全局永不遗忘、热记忆按周期转冷、冷归档用到即转热 | 自动注入，无需操作；右侧边栏可查看与整理 |
| 专家库 | 按岗位组织的专家视角，命中关键词才注入 | 直接提问；跨领域任务会说清用了哪几位 |
| 文档能力 | Word / Excel / PPT / PDF 的读取、生成、比对与转换 | 把文件交给助手，说清要做什么 |
| 思维链与图表 | 把 Mermaid 代码块渲染成流程图与时序图 | 代码块写在回复里自动出图 |
| 桌面形象 | 桌面上显示形象与用量面板 | 拖动、点击；设置在自己的分区里 |

## 四、目录与镜像（配置后要懂的）

- **只选一个存储根目录**：记忆体与知识库各自在它下面新建自己的文件夹（子目录名由插件下发，本版是 `memory-data` 与 `obsidian-data`）。已有配置若不是这套布局，页面显示为「已单独指定」并**原样保留**，绝不改写你的路径。
- **目录选择有三条路**：桌面外壳下优先用系统目录对话框（桌面壳 bridge → 宿主原生选择器）；载体不支持时自动转**应用内目录浏览器**（可逐级进入、可新建目录）；两条都不通时可直接**手动输入路径**。
- **导入卡只管知识库**：已有知识库**不会被自动搬**，由你指定文件夹后逐项对照导入。记忆体在「保存配置并开始」的执行链第 1 步已自动迁完，所以卡上不再提记忆。
- **镜像区一开始是空的属正常**：`00_全局记忆` 镜像不是配置时灌满的，而是在记忆库发生写入之后自动同步。
- **工具目录本版只有框架**：技能 / 脚本 / MCP 三个子目录是预留用途，本版不实现同步，需要什么请先手工放。

## 五、默认约定

首装即生效的两条：回答与推理使用简体中文；主对话负责拆解与核对，具体工作交专家子代理执行。两条写在随包的指令模板与记忆种子里，可由使用者改写。

## 六、数据与隐私

- 全部数据本地存放、明文、不联网、无遥测。
- 除使用者自己配置的模型服务外，不向外发送任何内容。
- 卸载插件不删除记忆数据与形象素材。

## 七、常见问题

### 配置里改了没生效？

多数设置即时生效；快照顺序一类需要重启 DSH 的项，说明里会标注。

### 文档任务报错？

先看「安装与检查」的 Python 依赖与 WPS 两项，再到文档能力组跑一次自检。

### 专家没有注入？

零命中不注入是设计如此。需要特定视角时直接点名，例如「用等保测评专家看这个」。
