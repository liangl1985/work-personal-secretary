# 工作秘书 · 使用说明

> 这份说明写给**不写代码的人**，看这一份就够。只想先把插件装起来，看随包的另一份「安装引导」。

## 这份说明怎么看

- 刚装好、想赶快用起来 → 看**第一节**和**第三节**。
- 想知道每个插件分别是干嘛的 → 看**第四节**（最长，也最值得看）。
- 想找某个功能在哪调 → 看**第七节**的对照表。
- 遇到问题了 → 看**第八节**。

## 一、它是什么

一句话：它把五样常用能力装进 DSH，让你的助手替你干重复的活，你只管判断和决定。

| 插件 | 它是干嘛的 | 你什么时候会用到 |
|---|---|---|
| **记忆库** | 替你把偏好、决定、项目进展记下来，每次对话自动带上这些背景 | 每次对话都在用（感觉不到，但一直在） |
| **文档能力** | 读写 Word、Excel、PPT、PDF：提取内容、套版式、做比对、转格式 | 要处理文件的时候 |
| **专家库** | 按不同行业的专业视角回答你（售前、财务、劳动法、代码、排版……） | 要写正式材料、要专业判断的时候 |
| **图表** | 把一段流程或结构描述直接画成图 | 要画流程图、架构图的时候 |
| **桌面小宠物** | 屏幕角落一个小形象：看用量、跟着任务做动作，还能帮你把提示词写清楚 | 想随时看到用了多少、想把话说得更清楚的时候 |

这五样可以只装你要的，互不依赖。装完之后，DSH 的设置里会多出一个**工作秘书**分区。

## 二、先认几个词

下面的词在后文反复出现，先花一分钟认一下，后面读起来会顺很多。

| 你会看到 | 它的意思 |
|---|---|
| 插件、子插件 | 给 DSH 加功能的程序包。这里一共五个，「集成体」是它们的外壳 |
| 集成体 | 把五个插件打成一个包的那个外壳程序（也就是你现在装的这个） |
| 记忆库 | 助手的记事本，存在你指定的文件夹里，是纯文本文件，能直接用记事本打开看 |
| 知识库 | 你自己的资料库（文档、笔记）；助手可以按你的指定往里读、往里写 |
| 存储根目录 | 上面两个文件夹的**上级目录**，你只需要选这一个，两个子目录由插件自己建 |
| 快照 | 每轮对话开始前，自动粘给助手的那一小段记忆摘要（标题默认是【记忆】） |
| 技能 | 一套预先写好的操作方法，助手干活时按它执行，你不用管 |
| 转冷、冷归档 | 太久没用到的记忆会被搬进归档文件夹休息；**仍然能搜到，用到就自动回来** |
| 专家视角 | 让助手换成某一行业的专业口径来回答，比如「用财务的角度看」 |
| 提示词 | 你对助手说的那段话；把它说清楚，回答质量差别很大 |

## 三、第一次使用：三步

### （一）先看有没有缺东西

打开**设置 → 工作秘书 → 安装与检查**，页面上有两个分组：

- **环境依赖**：Python、Python 依赖库、WPS 三项。绿色就是好的；红了就点右侧的**依赖安装工具**，它会给出该做什么。
- **子插件**：五样能力是否装上。没装的点**安装**。

### （二）填三个空

切到**核心配置**页，填三样：

1. **存储根目录**：只需要选这一个文件夹。记忆库与知识库会各自在它下面建自己的子目录（名字是 memory-data 和 obsidian-data，插件自动建，你别改名）。
2. **工作岗位**：你是干什么的，它会按岗位调整回答角度。
3. 页面下方会显示由根目录**自动派生**的两个目录；只有你想让它们放在别处时，才点「单独指定」去改。

选文件夹用页面上的**浏览…**按钮：桌面版会弹出系统的文件夹选择框；弹不出来时会自动切换成页面内的目录浏览，能逐级进入、也能新建文件夹；两条路都不通时，直接把路径粘进输入框。

三项齐了，点**保存配置并开始**。它会按顺序做六件事，页面上会一步步打勾：

1. 可用性检查（只看不改）
2. 迁移旧记忆库（如果你以前用过，把旧内容带过来）
3. 建立记忆库结构
4. 建立知识库结构
5. 把两者关联起来
6. 写入你的岗位身份

中途任一步失败会停在那一步、已经完成的部分保留，改完可以再点一次继续。

### （三）开始用

直接回对话里说话就行。第一次可以这样试：

> 帮我记住：我写方案习惯先列结论，再写依据。

## 四、五个插件分别介绍

这一节是整份说明的重点。每个插件都按同一套讲：**它是干嘛的 → 它自动做什么 → 你能让它做什么 → 在哪里看和改 → 有什么边界**。

### （一）记忆库

**它是干嘛的**

助手的记事本。你把偏好、决定、项目进展说给它，它记下来；以后每次对话，它自动带上这些背景，你不用反复交代。

**它自动做的三件事**

1. **每轮带上记忆**：对话开始前，它把全局记忆、你的偏好、项目记忆、今日日志拼成一段摘要交给助手（这段摘要的标题默认是「记忆」）。
2. **记今日流水**：每轮自动往「今天」的日志里补一条时间戳，十分钟内只记一次。这种流水只作留痕，不会塞进摘要占篇幅。
3. **自动瘦身**：太久没用到的记忆会搬进归档文件夹（日志 7 天、项目 30 天、偏好 90 天）。标了「关键」的永不搬家。**搬走不等于丢掉**，照样搜得到，一旦被用到就自动搬回来。

**你能让它做什么**

| 你想做的事 | 就这样说 |
|---|---|
| 让它记住 | 帮我记住：我下周三要交投标文件 |
| 问它记过什么 | 我之前说过方案怎么写来着？ |
| 改一条 | 把「下周三交投标文件」改成下周五 |
| 删一条 | 把关于李工的那条记忆删掉 |
| 建立关联 | 把「宁电投项目」和「资质材料清单」关联起来 |

重要的事它会先问你一遍：标成「关键」的记忆不会直接落盘，而是先进待确认队列，等你在面板里点批准。

**在哪里看和改**

右侧边栏 →「记忆库」。面板里有四件事：

- 顶部四个数字：全局、偏好、项目、待确认各有多少条；
- 按范围浏览条目，能直接搜索；
- 写新条目、批准或拒绝待确认、删除条目；
- 点开一条能看到它和哪些条目有关联。

在「项目」范围里还能新建项目分类，或者把某个做完的项目整体归档（归档只是移进归档文件夹，不会真删）。

**记忆分四类，各自去哪里**

| 类别 | 放什么 | 会不会每轮自动出现 |
|---|---|---|
| 全局 | 换个项目也成立的根本内容（你的长期习惯、红线） | 会 |
| 偏好 | 你的个人偏好与习惯 | 会 |
| 项目 | 与某个具体项目有关的事 | 会（条数有上限） |
| 日志 | 当天流水 | 只带当天几条 |

判断口诀是「换个项目还成立吗」：成立就进全局或偏好，不成立就进项目，当天的事进日志。你不用说，它自己判；判错了你直接说，它改。

**三条自动提醒**

摘要里会直接出现提醒：全局条目超过 20 条该整理了、超过 7 天没做周保养、有待判断的条目等你定夺。看到提醒就顺手处理一下。

**备份与镜像**

- **自动备份**：写库时触发，但**每天至多一次**（当天已备份过就跳过），保留最近 7 份。
- **镜像**：把记忆内容同步一份到你的知识库里（00_全局记忆 文件夹），方便你用笔记软件直接翻。**配置向导跑到最后一步（写你的身份）时会同步一次**，所以你配好就能看到内容；之后只在你「记住 / 建关联 / 冷记忆被召回」之后再同步。

**七条命令**（在 DSH 里直接输入）

| 命令 | 作用 |
|---|---|
| /memory_review | 看待确认的关键记忆（批准要回面板点） |
| /memory_archive | 立刻执行归档 |
| /memory_backup | 立刻手动备份 |
| /memory_audit | 分类巡检：各范围条数、可疑条目、关联枢纽与孤儿 |
| /memory_maintain | 周保养：到期转冷 + 未来 7 天到期清单 + 转热候选 |
| /memory_promote | 把归档里的某条按原样取回热区 |
| /memory_triage | 转冷预审：列队列、或逐条判保留/转冷 |

**边界（要知道的）**

- 记忆是**纯文本文件**，明文存在本地。标「敏感」的条目只是**不自动出现**在摘要里，**没有加密**。
- 备份不做自动恢复：要回滚得手工把备份文件拷回去。
- 只有一项设置改完需要重启 DSH（摘要顺序），其余 23 项改完即时生效。

### （二）文档能力

**它是干嘛的**

处理 Word、Excel、PPT、PDF 四种文件：读内容、改版式、做比对、转格式。你把文件交给助手，说清要做什么就行；它背后调的是本机的 WPS，**文件不离开你的电脑**。

**四种格式各能做什么**

| 格式 | 能做的事 |
|---|---|
| **Word** | 读全文与表格、从文字生成文档、批量查找替换、**两份文件比对**、**给已有文件套版式**、导出 PDF |
| **Excel** | 读写单元格、写公式并重算取值、做数据透视表、生成图表、合并多个工作簿、**给已有表格套样式** |
| **PPT** | 按大纲成套出稿（16 类页型、原生图表与表格、演讲者备注）、**给已有 PPT 统一字体**、提取文本、导出 PDF、逐页出图 |
| **PDF** | 提取文字、提取表格（带位置坐标）、读页数与文件元信息；合并、拆分、选页、页面转图片、图片合成 PDF |

**比对：能给你一份「红线条」**

两份 Word 的差异不是只打印一段文字，而是生成一份**能在 WPS 里直接打开的修订版**，改动按字符级标出来，逐条接受或拒绝。合同、方案改稿用这个最省事。

**套版式：给已有文件换装，内容一个字不改**

这是它最有用的功能之一，专门解决「内容没问题、格式太乱」。随包内置 **10 套规格**，**Word / Excel 与演示（PPT）分开列**，常用的直接说名字就行。

**一、Word 与 Excel**（加 `--spec`）

| 规格 | 用在哪 |
|---|---|
| 标准商务（standard） | 方案、报告、说明、对账这类常规材料 |
| 党政机关公文（govdoc） | 正式发文，按公文国标的版式（页边距、三号仿宋正文、层次序数字体） |
| 内部纪要（compact） | 内部备忘、纪要、草稿，密排小字 |
| 汇报报告（report） | 汇报、总结、复盘、数据分析报告 |

其中 **govdoc / compact / report 三套只用于 Word 与表格**（`standard` 是三格式共用的基准套，不在「专用」之列）：换成演示主题去套（比如 `dusk`）会被直接拒绝，并提示本格式能用的规格。

**二、演示 PPT**（加 `--theme`）

| 主题 | 用在哪 |
|---|---|
| 标准商务（standard） | 与技术方案、商务汇报通用，PPT 侧的基准主题 |
| 石墨工程（graphite） | 技术方案、架构说明、运维汇报 |
| 青蓝技术（teal） | 偏清爽的技术风介绍 |
| 酒红正式（wine） | 正式、有仪式感的场合 |
| 暗色商务（dusk） | 对外商务汇报、产品发布、客户宣讲 |
| 蓝色简约（azure） | 工作总结、项目汇报、阶段复盘 |
| 红色党政（crimson） | 党建与政务汇报、表彰大会、主题宣讲 |

其中 **graphite / teal / wine / dusk / azure / crimson 六套只用于演示 PPT**（`standard` 同上，是共用基准）：拿去套 Word 或表格会被直接拒绝，并列出该格式能用的规格（主题清单里也不会再出现它们）。

> 两边的名字有重复（标准商务）：它是 Word / Excel / PPT 三种格式**共用的基准套**，其余各套只写自己那一类的差异，没写到的自动沿用基准。所以同一套可以直接用在三种格式上，按上面两列选用最省事。

还有一条**安全设计**你要知道：套版式只改格式，落盘前会逐段（Word）或逐格含公式（Excel）比对内容，**只要发现内容有任何变化就拒绝写文件、原文件一动不动**。所以你不用担心它顺手改坏你的正文，最坏情况是它拒绝执行并告诉你原因。

**做 PPT：两条路，按你手上的东西选**

| 你手上有什么 | 走哪条 | 就这样说 |
|---|---|---|
| 已有 PPT，只是格式乱、字体杂 | **美化精修** | 把这份 PPT 的字体统一，内容一个字都不要改 |
| 只有一份大纲或想法 | **母版起手** | 用暗色商务那套母版，按这份大纲做一版 |

随包带 **三套现成母版**：暗色商务（对外商务汇报）、蓝色简约（工作总结与项目汇报）、红色党政（党建与政务汇报）。每套含一个母版加 11 个版式，封面、目录、章节页、图表页、结束页这些骨架都做好了。想用哪套直接说名字。

走母版路径要清楚它的边界：**工具只会自动套用其中第 1、2 个版式（标题页与内容页）**，其余 9 个版式是你在 WPS 里新建页时自选；如果你要的是「成套出稿」那种整册效果（封面／目录／章节页／图表页等十几类页型一次配齐），走的其实是**另一条不套母版的渲染路径**，跟这条不冲突。

母版来源是 WPS 主题库素材，公司内容已经全部去掉；`assets/manifest.json` 按项目所有者的授权口径标注为可随包再分发，并保留用途限定 —— **标准仅供参考学习使用，如用于商业化，一切后果由使用者自行承担**（完整表述见模块 `NOTICE`）。

**依赖什么**

- Python 3.10 以上 + 八个 Python 包；
- 本机装好 WPS（比对、重算、导出这三类操作靠它）。

两者**不会自动安装**，缺了会在「安装与检查」页标红并给出该敲的命令。

**边界**

- **扫描件不做文字识别**：整页是图片的 PDF，它会**提示你哪几页是扫描件**，但不会自动认字；要看的页我可以单独转成图片给你。要文字请提供电子版原件。
- 旧格式（.doc / .xls / .ppt / .wps / .et / .dps）与导出 PDF 走 WPS 调用，速度较慢，大文件要等一会儿。
- 公文规格只做**版式**：发文机关标志、发文字号、印章、页脚页码这些版头要素不生成。
- 表格套样式不支持合并单元格很复杂的表；遇到会明确告警，不会硬改。

### （三）专家库

**它是干嘛的**

内置 19 位「专业视角」，覆盖 6 个方向。它不改变助手是谁，只是让助手在回答时换上某一行的专业口径和方法。

| 方向 | 人数 | 包括 |
|---|---|---|
| 信息安全 | 4 | 工控安全售前、销售工程师、投标与方案策略师、等保测评 |
| 财务 | 4 | 会计师、税务师、财务分析师、内控合规 |
| 人力资源 | 1 | 劳动关系与劳动法 |
| 代码编程 | 3 | 软件工程师、DSH 插件工程师、代码审查与质量 |
| 金融 | 2 | 量化策略、投资研究 |
| 通用职能 | 5 | 事实核查、报告排版、文档与表格处理、演示设计、视觉设计 |

**它什么时候出现**

- 每个会话的**第一句**常驻一段专家目录（一共六行左右），让助手知道库里有什么——这段不占你每轮的篇幅预算；
- 你说话时它按关键词比对：**命中才请对口的专家进来**，没命中就一位都不请（这是设计如此，不是坏了）；
- 一个会话里**第一次命中**时，把命中的专家都给你看一眼精简卡；进入干活阶段后，每轮只让最相关的 1—2 位用全文说话。

**怎么指名用某位专家**

直接说就行，不用记 id：

> 用等保测评的视角看一下这份技术要求。
> 从财务角度帮我核一下这张报价表。
> 用劳动法专家看这份 offer 有什么风险。

**一条重要提醒**

信息安全、财务、金融、人力资源这四类共 11 位专家，标记为**未经专业复核**：它们给的是看问题的角度和方法，**不能直接当成测评结论、法律意见或税务处理对外交付**。对外用之前请让专业人员复核。代码与通用职能那 8 位不受此限。

**在哪里改**

**设置 → 插件 → 插件配置 → experts**，19 个选项。常用的几个：

| 想做什么 | 改哪一项 |
|---|---|
| 整个专家库关掉 | 总开关 |
| 告诉它你干哪一行（影响排序） | 本人岗位默认域 |
| 固定一个视角每轮都在 | 身份专家（留空＝不常驻，默认如此） |
| 只让某几个方向参与 | 参与匹配的域 / 专家 |
| 每轮给多少篇幅 | 注入字符上限（默认 15000） |
| 关掉「去哪拿技能」的指针 | 能力层指针开关 |

设置改完即时生效，不用重启。

### （四）图表

**它是干嘛的**

在对话里写一段画图代码，它直接把图渲染在你眼前，不用另开工具画完再截图贴回来。

**怎么用**

在回复里写一个画图代码块（标注 mermaid、mermaidjs 或 mmd 都认），它就会出图：

> 画一张图，说明投标文件的评审流程：形式评审 → 资格评审 → 响应性评审 → 详细评审。

**图出来之后能做什么**

- **切换**：每张图都能在「图形」和「代码」两种视图之间来回切；
- **全屏**：放大看细节，支持缩放、拖动、恢复 100%、适应窗口；
- **导出**：把图存成独立的 SVG 文件，可以直接插进文档或 PPT；
- **出错不慌**：代码写错时它不会留一张坏图，而是干净地退回显示代码，你改完再看。

**边界**

- 画图引擎是随包自带的，**不联网**也能用；
- 单张图超过 5 万字符或 2000 行时会拒绝渲染并显示源码（避免把页面卡住）；
- 只处理代码块，不处理行内代码。

### （五）桌面小宠物

**它是干嘛的**

屏幕角落一只常驻的小形象。它有三个用途：跟着任务状态做动作给反馈、点开看用量统计、**帮你把提示词写清楚**。

**基本操作**

| 操作 | 效果 |
|---|---|
| 单击 | 打招呼，并打开或收起统计浮窗 |
| 按住拖动 | 换位置，松手记住；窗口变小或换屏时它会被自动拉回可视区 |
| 键盘 | 宠物获得焦点后按 Enter 或空格同样能开关面板 |

它一直待在桌面上，切会话、开新会话都不会消失。

**它会跟着你的任务变**

形象有 12 个动作：空闲、工作中、压缩中、整理中、上下文预警、状态更新、打招呼、已归档、工具完成、工具失败、提示生成中、提示已就绪。你不需要操作，它自己判断：一轮任务开始就进入工作状态，工具跑完切成成功或失败，上下文开始压缩就做「吃 / 消化」，占用越过 90% 就预警。

宠物右上角有一枚小标签写着当前状态，下方有一枚小药丸显示「上下文 N%」，鼠标悬停能看到完整提示。

**统计面板（点一下宠物打开）**

面板分三个页签，标题栏还有「增强提示词」「刷新」「收起」三个按钮。

**总览页**能看五块：

1. **当前上下文**：占用百分比和「已用 / 窗口总量」，下面一条三色构成条告诉你系统、工具、对话各占了多少；
2. **当前会话明细**：输入、输出、缓存读、缓存写各多少 token，以及工具调用次数、轮次、步数、模型耗时；
3. **终身用量账本**：跨会话永久累计的总量与经历过的会话数，可以展开看分类。右上角有「清空历史」——**点了就永久清空、不能撤销**，会先弹一个红字确认框；
4. **用量最高的 5 个模型**：看看你的额度都花在哪了；
5. **今日用量趋势**：今天按小时的 token 折线图，鼠标悬停能看到那一小时用了多少、请求几次。趋势要先用一次「首次建立索引」；

**模型页**列出所有「服务商 · 模型」的累计用量。**设置页**就是下面那些开关。

**提示词增强（这个功能值得单独说）**

*解决什么问题*：我们写提示词常常一句话里塞了太多隐含要求，助手漏条件、抓不住格式。这个功能让你把原始想法交给当前模型，按固定规则改写成更清楚、更可执行的提示词，再由你决定用不用。

*怎么用*：

1. 打开统计面板，点标题栏的**增强提示词**，右侧（窄屏是底部）滑出一个抽屉；
2. 抽屉里第一个框是「原始提示词」，会自动带上你已经在输入框里写好的草稿；
3. 点**增强提示词**按钮，等它算完；
4. 结果显示在第二个框「增强结果（可编辑）」里，你可以先手改；
5. 然后选一个动作：

| 按钮 | 意思 |
|---|---|
| 覆盖原文 | 用增强结果替换你输入框里的原文 |
| 插入末尾 | 原文 + 增强结果一起放回输入框 |
| 复制增强版 | 只复制到剪贴板 |
| 重新生成 | 对同一份文本再来一次 |
| 撤回增强 | 恢复增强前的原文 |
| 直接发送 | 把增强结果交给输入框并直接提交 |

*两个状态看得见*：增强过程中，按钮变「增强中…」并全部禁用，宠物播放「提示生成中」、徽章变紫色；结果出来后，宠物播放「提示已就绪」、徽章变绿色，按钮组展开成上面六个。

*它守的规矩*：只改写提示词、**不执行**里面的任务；保留你的原意、语言、事实、数字、专有名词和所有明确约束；不编造事实、不增加你没提过的目标；中文提示自动走中文规则。

*边界（重要）*：

- **必须你手动点才发生，它绝不自动改写、绝不自动发送**；
- 增强会**额外消耗 token**；
- 切换会话后旧结果作废，要在当前会话重新增强；
- 已经点过「直接发送」的消息**不能撤回**；
- 单次输出有长度上限（约 2048 token），特别长的提示词会被截；
- 要能用这个功能，得先勾上「启用提示词增强」（默认是开的），并且当前能取到可用的模型；取不到时会明确报错，不会假装成功。

**完成提示音（可选）**

勾上以后，当前会话一次回复**成功结束**时响两声短音。工具结束、取消、失败、翻历史、切会话都不响。默认是关闭的；开启前建议先点一次**试听**确认这台机器能出声——浏览器可能拦截自动播放，试听只解锁声音、不会顺带打开自动提示音。

**换形象**

- 随包带三套形象，在设置里的**形象套装**下拉里选，选完立即生效；选中后还能点「设为默认形象」（清缓存或重装后回落到它）；
- **自己加一套**：把形象文件夹放进运行时的形象目录（DSH 数据目录下的 workspace-tokenpet/skins/，里面要有 manifest.json 加每个动作的图），刷新页面就出现在下拉里，**不用重启、不用重装**；删掉文件夹就从列表消失；
- 某套形象缺某个动作时，会自动用内置素材顶上，不会显示空白；
- 集成体安装时会把随包形象部署到这个目录，规则是**只补缺失、绝不覆盖你改过的**。

**在哪里改设置**

两处入口，改的是同一套开关：**DSH 设置页里的「小宠物设置」分区**，或者**统计面板的「设置」页签**（面板收起时也能改）。能改的有：宠物大小（64–320 像素）、动画速度（0 就是完全静止）、低性能模式、界面语言（中文 / English）、完成提示音、形象套装、增强模板与增强模型，以及「维护与高级」里的趋势索引维护。

**它没有的功能（别去找）**

- **没有透明度调节**；
- **没有「关闭宠物」的开关**：它是常驻的，只能收起统计面板；
- **没有命令**：它的入口就是单击宠物、面板按钮和设置页；
- 偏好保存在浏览器本地，换浏览器或清缓存会丢，需要重新选一次形象。

## 六、我的东西存在哪

**只有一个根目录**

你在核心配置页选的**存储根目录**就是根。它下面由插件自动建两个文件夹：

| 文件夹 | 装什么 |
|---|---|
| memory-data | 记忆库：你的偏好、决定、项目记录、日志、归档 |
| obsidian-data | 知识库：你的资料、笔记、文档，以及 00_全局记忆 镜像 |

这两个名字是插件定好的，别改名、别搬走；要换位置就在设置里改根目录。**如果你以前已经填过别的路径**，页面会显示为「已单独指定」并原样保留，它不会擅自改你的路径。

**镜像区什么时候有内容**

镜像就是把记忆同步一份到知识库的 00_全局记忆 文件夹里，方便你用笔记软件直接翻。**配置向导跑到最后一步（写你的身份）时会同步一次**，配好就能看到内容；之后每次记忆库**发生写入**（记住 / 建关联 / 冷记忆被召回）也会再同步一次。

**工具文件夹里有什么**

知识库里会看到一个工具文件夹，下面分技能、脚本、MCP 三个子目录。**随包已经写好两份内容**：一份工具总览（说明三个子目录各放什么），一份《DSH 与插件使用技巧》（长文，条目分「官方规定／本机实测／本项目约定」三类，放在技能子目录下）。这两份之外的**持续同步仍未实现**，需要什么先手工放进去。

**已有旧知识库怎么搬**

核心配置页有一张「已有旧知识库要带过来？」卡片，它**只管知识库**：你指定旧文件夹后逐项对照导入，**不会自动搬你的东西**。记忆不用你操心——点保存时第 2 步已经自动迁完了。

## 八、常见问题

**Q：我改了设置，好像没生效？**

A：多数改完立刻生效。只有少数会写明「需要重启」，那就重启一次 DSH。记忆库里唯一需要重启的是「摘要顺序」。

**Q：它没有记住我说的事？**

A：三种常见情况。一，你只是顺口提了一句，没说「帮我记住」——直接说这句最稳。二，那是当天流水，进了日志区，不在面板首屏。三，条目太久没用转冷了，但它仍能被搜到，用到就会回来。

**Q：我说了不要记，它还是记了？**

A：直接说「把这条删掉」，或者去右侧边栏的记忆库面板删。面板里删除前会再问一次，删了就找不回。

**Q：文档功能报错怎么办？**

A：先看「安装与检查」页的 Python 与 WPS 是不是绿的；再确认 Python 是 3.10 以上；然后按页面给的命令补装缺的包。装完 Python 或 WPS 后要**新开一个命令行窗口**、并在页面上点一次「重新检测」，它才能读到新环境。

**Q：为什么扫描件 PDF 读不出文字？**

A：扫描件整页是图片，本版本不做本地文字识别。它会把那几页转成图片给你看；要文字请提供电子版原件。

**Q：套版式会不会把我的正文改坏？**

A：不会。它在落盘前会逐段（Word）或逐格连公式（Excel）比对内容，**只要发现内容有任何变化就拒绝写文件、原文件一动不动**，并告诉你原因。它还会先生成一份带时间戳的备份。

**Q：专家视角没有出现？**

A：默认是「命中关键词才注入」，没命中就一位都不出现，这是设计如此。需要特定视角时直接点名，例如「用等保测评专家看这个」。

**Q：桌面小宠物挡住了东西，怎么关掉？**

A：**关不掉**——它是常驻的，只能单击收起统计面板。嫌它碍事就把它拖到角落，或者把大小调小、动画速度调到 0。

**Q：换电脑怎么迁移？**

A：把你的知识库目录整体拷过去（记忆镜像就在里面），在新机器的核心配置页指到它，记忆就跟着回来了。

**Q：怎么备份？**

A：直接把存储根目录整个复制一份就是备份。记忆库另外还会按设置里的份数自动备份。

**Q：数据会上传到网上吗？**

A：不会。所有数据都在本机、明文存放，没有遥测。除了你自己配置的模型服务，不向外发送任何内容。提示词增强会把那段文字交给**你自己配置的模型**，这是你点它才会发生的动作。

**Q：我完全不懂技术，出问题找谁？**

A：把报错整段复制发给助手，让它看。多数问题它能直接定位并给出处理办法。

## 九、升级、卸载与数据留存

**升级**：在「安装与检查」页点升级。内部会先把新版本下到临时目录、逐个文件校验、再整体替换，中途失败不会留下半成品。

**卸载**：

```text
dsh plugin --profile desktop remove <包名>
```

卸载后重启 DSH。**你的数据不会被删**：

| 内容 | 卸载后 |
|---|---|
| 记忆内容 | 保留在存储根目录下 |
| 知识库 | 保留原处 |
| 桌面形象素材 | 保留在 DSH 数据目录的 workspace-tokenpet/skins 下 |
| 宠物偏好（大小、位置、形象选择） | 保留在浏览器本地 |
| 插件本身 | 被移除，重装即回到可用状态 |

## 十、默认约定

首装即生效的两条，写在随包的指令模板与记忆种子里，你可以随时改写：

1. **回答与思考都用简体中文**；代码、命令、路径、报错原文保留英文原样。
2. **主对话负责拆解与核对，具体工作交给专家子代理执行**；涉密或敏感内容由主对话直接处理。
