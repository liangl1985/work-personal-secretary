工作秘书 · 安装引导

这份指引写给第一次安装 DSH 插件的人。全程不需要懂编程，也不用记住任何命令。 两种装法任选一种：不想敲命令就走「方式一」，把一段话复制给 DSH，剩下的交给它；习惯自己动手就走「方式二」。

一、先弄清楚：要装什么、装完能做什么

「工作秘书」是一个能力包，装进 DSH 之后，你的对话助手就多了五样本事。它们各自独立，可以只装你要的：

插件它是干嘛的
记忆库替你把偏好、决定、项目进展记下来，每次对话自动带上这些背景
文档能力读写 Word、Excel、PPT、PDF：提取内容、套版式、做比对、转格式
专家库按不同行业的专业视角回答你（售前、财务、法务、代码、排版……）
图表把一段流程或结构描述直接画成图
桌面小宠物屏幕角落一个小形象：看用量、跟着任务做动作，还能帮你把提示词写清楚

每个插件具体怎么用，看随包的使用说明（「安装与检查」页有入口）。

装完之后，设置里会多出一个工作秘书分区，下面四个页签：安装与检查、核心配置、配置、关于与致谢。

二、动手之前，确认三件事

要确认的事怎么确认不符合怎么办
你已经在用 DSH Desktop能打开 DSH 的对话窗口先去装 DSH Desktop，装好再回来
你手上有「工作秘书集成体」文件夹里面有 modules 文件夹，里面又有几个插件文件夹从发布页下载或克隆这个集成体仓库
需要时能装软件装 Python 和 WPS 时会弹权限提示用管理员账号登录，或找管电脑的人帮忙

集成体文件夹放在哪都行，路径里尽量别有中文和空格，能少一类麻烦。

三、两种安装方式，选一种

方式一：交给 DSH 装方式二：自己动手装
适合谁不想碰命令行的人习惯自己操作的人
你要做的复制一段话发给 DSH，然后按它说的做照着下面的命令一步步敲
大概耗时5 分钟（不含下载）10 分钟（不含下载）
出错时把报错原文贴给 DSH，它会接着处理对照第六节排查

方式一：把下面整段复制给 DSH

第一步：复制下面方框里的全部文字（从「我刚拿到」到「谢谢」）。

我刚拿到一份 DSH 插件集成体，名字叫「工作秘书」。请你帮我装到本机 DSH 上，全程你来做，我不懂命令行。

请按这个顺序办：
1. 先确认本机 DSH 可用：运行 dsh --version，把版本号告诉我。
2. 再找到这份集成体的文件夹。如果找不到，直接问我路径，不要猜。
3. 装本体，命令是：dsh plugin --profile desktop add <集成体目录>/modules/work-personal-secretary
   如果我的 DSH 用的不是 desktop 这个 profile，请告诉我怎么查、怎么换。
4. 装完告诉我一句「需要重启 DSH」，我重启完再回来找你。
5. 重启之后，帮我把五个子插件装上：dsh-work-memory、dsh-doc-suite、dsh-experts、dsh-mermaid、workspace-tokenpet。
   能命令行装就命令行装；不能的话，告诉我应该点界面里的哪个按钮，我来点。
6. 运行环境也要帮我看看：Python 3.10 以上、八个 Python 包、WPS Office。先检测哪些已经有，只装缺的，装之前把命令给我看一眼。
7. 最后帮我核对一遍：环境依赖是否全绿、五个子插件是否都装上了，用一张小清单告诉我。

做事的时候请注意：
- 每做完一步，用一句话告诉我结果和下一步要我做什么，不要一次说一大堆。
- 报错就把原始报错发我，并给出解决办法；不要跳过错误继续往下做。
- 不要动我其他的插件，不要删我的文件；如果某一步会覆盖或删除东西，先问我。
- 装的东西如果很大或者要下载很久，先跟我说预计多大、多久。

谢谢。

第二步：把这段话粘贴到 DSH 的对话框里发送，然后按它说的做（它可能会问你文件夹在哪、要不要重启）。

第三步：它说需要重启时，重启 DSH 一次。

第四步：重启后回到这里，走第五节的六项检查。

方式二：自己动手装

第 1 步 · 装本体。打开命令行（Windows 上推荐 PowerShell），执行：

dsh plugin --profile desktop add <集成体目录>/modules/work-personal-secretary
  • 把 <集成体目录> 换成你那份集成体文件夹的真实路径，两边不要留尖括号。
  • 把 desktop 换成你自己的 profile 名（桌面版默认就是 desktop）。
  • 命令执行完没报红字、最后一行类似「added」就是成功。

第 2 步 · 重启 DSH。本体要重启之后才会在设置里出现。

第 3 步 · 装五个子插件。重启后打开 DSH，进设置 → 工作秘书 → 安装与检查，在「子插件」分组里逐个点安装；也可以点整批安装，它会一项一项做、做完立刻回显。

第 4 步 · 看缺什么。同一页看「环境依赖」分组：缺哪一项，点右侧的依赖安装工具，它会给出该敲的命令。页面上还有查看安装引导与使用说明两个入口，随时可以回来看。

四、运行环境与程序安装

先把结论说清楚，省得你装了半天发现不该装：

要装的东西必须吗不装会怎样
Python 3.10 以上（建议 3.12）必须（文档能力要用）文档功能全不可用
八个 Python 包必须（文档能力要用）文档功能全不可用
WPS Office必须（文档比对、重算、导出要用）文档的比对、重算、导出用不了
Obsidian可选只是看不到知识库与记忆镜像
桌面形象可选屏幕上没有小形象，其他功能照用

这个能力包不会替你安装解释器或 WPS。要么你自己装，要么按下面「交给 DSH」的方式让它装。

4.1 Python

交给 DSH（省事）：把下面这段话发给 DSH。

请帮我在本机装好工作秘书需要的运行环境，我不懂命令行。

1. Python：需要 3.10 以上，建议 3.12。先查本机有没有（Windows 上用 py -3 --version 查），已经有了就跳过。
2. 八个 Python 包：python-docx、openpyxl、python-pptx、PyMuPDF、pdfplumber、pypdf、Pillow、pywin32。
3. WPS Office：装完不用额外配置。

要求：先检测、只装缺的；每条命令先给我看再执行；需要管理员权限时提醒我；装完用一张小清单告诉我哪些是新装的、哪些原本就有。

自己装：Windows 上用这行命令（会从微软的应用商店源安装）：

winget install -e --id Python.Python.3.12 --accept-source-agreements --accept-package-agreements --silent
  • 装完新开一个命令行窗口再验证，输入 py -3 --version，能看到版本号即可。
  • Windows 上请用 py -3 来调用，不要用 python：它可能是应用商店的占位程序，看着像装了其实没装。
  • 如果你是从官网下载安装包手动装的，安装向导第一屏记得勾上「Add Python to PATH」。

4.2 八个 Python 包

Python 装好后，命令行执行：

py -3 -m pip install python-docx openpyxl python-pptx PyMuPDF pdfplumber pypdf Pillow pywin32

每个包是干什么的：

包用途
python-docx · openpyxl · python-pptxWord / Excel / PPT 的读写与样式
PyMuPDF · pdfplumber · pypdfPDF 的文本、表格与页面操作
Pillow图片处理（插图、导出图片）
pywin32调用本机 WPS 完成比对、重算与导出
  • 网络慢或装不动时，在命令末尾加：-i https://pypi.tuna.tsinghua.edu.cn/simple。
  • 这一步不需要管理员权限；如果报权限错误，多半是装到了系统目录，改用上面的命令重来一次。

4.3 WPS Office

自己装：

winget install -e --id Kingsoft.WPSOffice.CN --accept-source-agreements --accept-package-agreements --silent
  • 装完不需要额外配置，插件会直接调用本机已有的 WPS。
  • 文档能力依赖 WPS 的商用许可；这个能力包不会做任何代理或破解动作。
  • 已经装了 Microsoft Office 也建议补装 WPS：比对、重算、导出这三类操作走的是 WPS。

4.4 Obsidian（可选）

只用于看知识库与记忆镜像，不装不影响其他能力。想要就自己去官网装，装完不用配置，插件会自动对接。

五、装完自己验一遍

回到设置 → 工作秘书 → 安装与检查，对照下表逐项看：

检查点在哪看正常的样子
环境依赖「环境依赖」分组Python、Python 依赖、WPS 三类都是绿色
子插件「子插件」分组五种子插件都显示已装，且版本不低于内置版本
旧知识库「已有旧知识库要带过来？」卡片有旧知识库才用它；没有就忽略
核心配置切到核心配置页记忆库目录、知识库目录、工作岗位三项都填好
一键配置核心配置页的执行链点保存配置并开始后，四步依次打勾
实际能力回对话里试一句让它读一份 Word，能读出来就说明链路通了

六项逐条对过、都没有异常，安装就算完成。哪一项不对，看下一节。

六、出问题了怎么办

命令行提示找不到 dsh：DSH 的命令行工具没加进系统路径。改用 DSH 自带的命令行窗口，或者走方式一让 DSH 自己装。

装完重启了，设置里还是没有「工作秘书」：多半是装到了别的 profile。确认命令里的 profile 名和你实际在用的是同一个（桌面版默认 desktop），然后重启一次。

子插件装上了，但「环境依赖」还是红的：环境是独立检测的，装完 Python 或 WPS 后要新开一个命令行窗口、并在页面上点一次重新检测，它才会读到新的环境。

文档功能报错：先看「安装与检查」页的 Python 依赖与 WPS 两项是不是绿的；再看装的是不是 3.10 以上；然后按页面给的命令补装缺的包。

Windows 上找不到 py -3 命令：说明 Python 没装好或没进系统路径。重装时勾上「Add Python to PATH」，或直接用 winget 那条命令重装。

五个子插件里某一个装不上：先看是不是缺前置环境（文档能力需要 Python 与 WPS）；也可以只装需要的那几个，五个之间没有依赖顺序。

忘记把集成体文件夹放哪了：在 DSH 里直接问「帮我找一下本机的工作秘书集成体目录」，它会替你搜。

七、升级与卸载

升级

在安装与检查页点升级即可。插件内部的做法是：先把新版本下到临时目录、逐个文件校验完整性与哈希、再整体替换，并同步更新 profile 的登记。中途失败不会留下半成品，不需要你手工清理。

卸载

dsh plugin --profile desktop remove <包名>
  • 卸载后重启 DSH。
  • 你的数据不会被删：记忆内容、知识库、桌面形象的素材都保留在原处，重装后照旧可用。
  • 桌面形象的素材位于 DSH 数据目录下的 workspace-tokenpet/skins 文件夹，属于你自己的资产；插件文件夹里那份只是随包附带的副本，安装时只补缺失、不覆盖你改过的。
