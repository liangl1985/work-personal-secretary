# templates/（母版与主题骨架）

**当前状态：随包只含本说明；母版 pptx 不随包**（渲染主线不依赖母版）。

## 用途

- 渲染主线是**代码几何** —— `specs/*.json` 的 `pptx` 段是唯一真值，**渲染器不读母版**；
  内置风格（含 `report` 汇报报告）一律在 `specs/` 随包交付，不需要任何母版文件。
- `templates/<theme>/skeleton.pptx` 为**可选**的母版骨架，只在「导入公司母版、提取主题 / 版式」时用到。
- 使用者自定义层：`~/.dsh/data/dsh-doc-suite/templates/`（主题规格 json 与公司母版 pptx 放这里，
  同名文件覆盖内置层；目录级合并规则见 55 号第六章）。
- `ppt_theme.py import <母版.pptx> --id <id>` 属**一次性令牌提取**：把色板 / 字体 / 页面尺寸写成
  自定义层主题 json；此后渲染**不再需要**那份 pptx。

## 发布纪律

**内置层必须中性**：公司口径、母版与素材一律放自定义层，发布件不带。
