# templates/（使用者自定义层说明）

**本目录随包只含本说明。** 原来放在这里的「母版骨架」约定已调整，两处分工如下：

| 放哪 | 谁用 | 说明 |
|---|---|---|
| `assets/templates/<id>.pptx` | **随包内置**，所有人可用 | 三套母版：`dusk`（暗色商务）/ `azure`（蓝色简约）/ `crimson`（红色党政），各 1 个母版 + 11 个版式；制作时用 `ppt_tool.py create --template` 继承 |
| `~/.dsh/data/dsh-doc-suite/templates/<id>.json` | **使用者自定义层** | 样式规格（与内置 `specs/*.json` 同名覆盖）；公司口径、私有风格放这里，**不进发布件** |

## 渲染主线不依赖母版

- `ppt_render.py` 的几何真值是 `specs/*.json` 的 `pptx` 段，**不读任何 pptx 母版**；
- `ppt_theme.py import <母版.pptx> --id <id>` 是**一次性令牌提取**：把色板 / 字体 / 页面尺寸写成自定义层主题 json，此后渲染不再需要那份 pptx；
- 导入公司母版时**只搬视觉令牌、不搬内容**（文字、图片、版式一律不提取）。

## 发布纪律

**内置层必须中性**：公司口径与公司母版一律放自定义层，发布件不带。随包 `assets/templates/` 的三套母版已逐份核查：公司基底母版、业务页、业务图、批注作者与元数据全部清除。
