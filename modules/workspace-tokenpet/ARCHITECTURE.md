本文件只描述**已在代码里实现**的行为，结论一律带出处。文内路径均**相对于本模块根目录**（`modules/workspace-tokenpet/`）；宿主源码行号对应 `src/*.ts`（`README.md:93` 明示 **`src/**` 是唯一真源**，`lib/**` 与 `client/client.js` 是随包分发的构建产物）。当前包版本 **1.0.1**（`package.json:3`）。

## 1. 架构

**这个模块是什么、替谁做什么**：一个**宿主半 + 浏览器半**的 DSH 插件（`README.md:11-17`）——在 DSH Web 界面上悬浮一只「用量小宠物」，按会话的上下文压力与 token 用量播动作，并提供用量/上下文面板、形象套装发现、提示词增强面板与设置分区。

### 体积事实（客户端 bundle）

- **`client/client.js` = 21.93 MiB（22,992,786 B）**，其中内嵌 **12 条 `data:image/webp;base64`**：base64 字符 22,900,509，解码后 **16.38 MiB**；生成源 `pet-action-sheets.generated.ts` 为 21.47 MiB（base64 字符 22,507,900，解码 16.1 MiB）。即约 **22 MB 的 bundle 里约 16 MB 是 base64 WebP 图集**。
- **它随页面启动一并加载**：bundle 自身以 `window.__ModuleLoader__.load({ id: "workspace-tokenpet", factory … })` 自注册（`client/client.js:1`；由 `tsdown.config.mjs:40-42` 注入 banner/footer，:2 说明由 dsh web 插件表在 `/plugins/workspace-tokenpet/client.js` 提供）。宿主侧 `@deepseek-ai/dsh-client-modules/lib/index.js:183` 把各插件客户端 bundle 组合成 `/plugins/??<id>/client.js,…&rev=…` combo URL，其 `README.zh.md:74` 说明宿主注入 `window.__ModuleLoader__` queue facade、application combo 的 preload 与**阻塞 parser 的 bootstrap combo 脚本**后，才进入外壳启动；`README.zh.md:46` 另说明客户端 bundle 必须构建好，缺失会「大声失败」。本模块 `README.md:93-95` 同口径：产物随包分发、宿主按 id 装载客户端半。
- 该体积不进入发布物的额外副本：`tsdown.config.mjs:24-27` 刻意不产出 sourcemap、也不单独分发 action-sheet 文件（它们与内嵌字节重复）。

## 4. 回退与恢复

### 版本回退

1. **改版本号 → 重新构建 → 重装**：`package.json:3` 的 `version`（当前 `1.0.1`）是安装器判定的版本口径；回退时把版本号改回目标值，`npm install && npm run build`（重出 `lib/` 与 `client/client.js`），再由集成体安装器重装。
2. **集成体安装是原子替换**：安装器把 `modules/workspace-tokenpet` 整体复制到 `<profile>/node_modules/workspace-tokenpet` 并写入 profile 的 `dsh.profile.bundles`，过程为**原子替换 + 逐文件 SHA256 校验，失败即回滚**（`README.md:61-63`）。
3. **开发态手动挂载**：`dsh plugin --profile desktop add link:<本模块目录>`（`README.md:72-76`）；**宿主半改动需重启 DSH Desktop，只改客户端时刷新页面即可**（`README.md:76`）——即客户端回退有时不需要重启。
4. **`git revert`**：源码与素材都在仓库内，回到历史提交后按上面重建/重装；版本历史见 `CHANGELOG.md`（顶部为最新条目，`CHANGELOG.md:10`）。

### 数据备份与恢复

- **运行时数据目录**：`<dsh home>/data/workspace-tokenpet/`（`README.md:78-82`）。备份 = 复制该目录；恢复 = 还原文件后重启。目录内文件：`baseline.json`、`session-usage-index.json`、`lifetime-ledger.json`、`hourly-trend-index.json`（出处见 §2 落盘表）。
- **可逆的清空**：`POST /usage/reset` 不删底层会话数据，只记 `(model, day)` 偏移并把旧偏移压栈；`POST /usage/restore` 弹栈还原（`src/baseline.ts:4-9`）。
- **账本有备份层**：`lifetime-ledger.json` 写入时保留 `.bak`（`src/lifetime-ledger.ts:225-238`）；同目录还有 `.lock` 与 recovery 机制（:150、:241-306）。
- **索引可重建**：`session-usage-index.json` 只是优化，条目缺失/损坏/指纹变化时调用方**回退折叠会话日志**（`src/session-usage-index.ts:1-5`）；丢失不会让用量聚合失败。

### 不可逆操作与注意事项

- **`POST /workspace-tokenpet/usage/lifetime/clear-history` 不可逆**：契约常量为 `'CLEAR LIFETIME LEDGER'`（`src/lifetime-contract.ts:1-2`），`src/lifetime-ledger.ts:1` 自述为「**non-rollback**」；宿主端强制校验确认串（`src/index.ts:929` 比对不符即拒），客户端提交时带上该常量（`src/client/lifetime-ledger.ts:13-24`）并展示 `lifetimeClearWarning` 警告文案（`src/client/lifetime-ledger.ts:6-10`）；趋势维护面板另有 `window.confirm` 重建确认（`src/client/trend-maintenance-panel.tsx:68`）。
- **形象部署策略：只补缺失、绝不覆盖**：安装器把 `<repoRoot>/modules/workspace-tokenpet/skins` 部署到 `<dsh home>/data/workspace-tokenpet/skins/<套装>/`；新址缺某套装而旧址 `<dsh home>/data/dsh-token-pet/skins/` 有同名套装时**复制迁移**，旧址数据保留；单套失败只清理该套半成品，**不影响插件安装结果**（`README.md:65-70`；实现与契约在集成体安装器：`../work-personal-secretary/lib/install.js:122-134` 定义 `SKINS_DIR_NAME` / `PET_SKINS_SUBDIR` / `LEGACY_PET_SKINS_SUBDIR`，:218-230 说明部署必要性）。
- **模块内的 `skins/` 运行时不会被读取**：运行时只从 `<dsh home>/data/workspace-tokenpet/skins/` 读（`../work-personal-secretary/lib/install.js:218-219`；本模块侧 `src/skins.ts:81-82`）。**手改模块内素材对运行时无效**，要增删形象请直接操作运行时目录（`README.md:81`、:17）。
- **清浏览器状态会丢偏好**：偏好只在 `localStorage` / IndexedDB（§3）；且 1.0.0 重命名后**旧键偏好不会自动继承**，需在「桌面形象」面板重新确认（`CHANGELOG.md:45-47`）。
- **体积提示**：客户端 bundle 21.93 MiB 随页面启动经 combo 脚本加载（§2），回退/热更客户端时要注意首屏加载成本；发布物中不含 sourcemap 与独立 action-sheet 文件（`tsdown.config.mjs:24-27`）。
- **未核实/未实现项**：
  - `pet-action-sheets.generated.ts` 头部声明的生成脚本 `scripts/build-runtime-from-freecut.py` **本版未随包提供**，无法从仓库内复现生成过程（内容可由 `CHANGELOG.md:16-17` 记录的「入库 bundle 反提 + 上游基线交叉验证」佐证，但那是历史记录，不是脚本）。
  - 本模块**没有** DSH 工具、命令、宿主设置命名空间与 HTTP 之外的对外集成点（§3 已核）。
